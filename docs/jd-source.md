## 关键要求摘要

- 工具线上化、数据服务、模型算法相关后端开发
- 高可靠、高安全、高性能通用服务模块
- Go/Python 至少一门 + Web 框架
- Linux + Redis + MySQL + 消息队列
- 模块化、可复用、可扩展的架构能力
- 大模型工程化应用经验优先

## 映射原则

本仓库采用如下映射策略：

- JD 硬技能优先落在后端主链路（Gateway/Rule/Case/Data/Worker）
- AI 能力只作为增强模块（Copilot），不替代主业务判定
- 通过指标与审计机制体现工程化交付质量
