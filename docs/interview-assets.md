# Interview Assets

## 简历 Bullet

- 设计并实现内容质量与数据服务平台，基于 Go + Python 搭建事件接入、规则判定、案例流转和数据服务主链路。
- 接入 AI Copilot 用于案例摘要、规则解释和误判复盘辅助，并通过结构化接口保证可回退、可审计。
- 建立事件时延、案例生成成功率、证据完备度和 Copilot grounding coverage 等指标，打通平台能力与业务价值表达。

## 项目讲解顺序

1. 业务问题：内容质量治理不能依赖分散脚本和人工流程
2. 系统设计：gateway -> evaluation -> case workflow -> data service -> copilot
3. 工程细节：Redis/MQ/审计日志/回放机制如何保障稳定性
4. 结果表达：误判复盘效率、服务化能力、可扩展性

## 高频追问清单

- 缓存与数据库一致性如何处理？
- 消息重复消费如何保证幂等？
- 如何做服务拆分并保持模块可复用？
- 稳定性治理如何做指标闭环？
- 内容质量平台为何需要独立数据服务层？
- AI 功能失败时系统如何兜底？

## 自我介绍主线

- 这是一个后端平台项目，不是单点模型 demo。
- 我重点展示业务抽象、服务架构、中间件治理和 AI 增强边界设计。
